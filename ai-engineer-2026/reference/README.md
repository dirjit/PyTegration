# Reference

> The appendix to the curriculum: the stack to learn, how to read benchmarks,
> what every term means, and where to read more. Use it as a lookup, not a
> linear read.

The lessons in [`../curriculum/`](../curriculum/) teach the *job*. This folder is
the **reference shelf** you reach for while doing it.

| File | What it's for |
|------|---------------|
| **[the-stack.md](the-stack.md)** | What to actually learn and what to skip — primitives first, then one production framework deeply (Claude Agent SDK as reference harness; LangGraph + Deep Agents for production; one observability tool). Includes the layered-stack diagram and a framework comparison table. |
| **[benchmarks.md](benchmarks.md)** | **Benchmark literacy, not numbers.** What SWE-bench / GAIA / τ-bench measure, why the same model swings ~10–36 points across harnesses, how to read a leaderboard critically — and why you build your own evals anyway. |
| **[glossary.md](glossary.md)** | Alphabetized definitions for every key term — agent loop, context primitives, harness, hooks, RAG, ReAct, regression gate, and the rest — cross-linked to lessons. |
| **[further-reading.md](further-reading.md)** | A curated, phase-organized reading list of primary sources (papers, provider docs, OWASP), with no invented links. |

> ⚠️ **Frameworks and numbers churn.** [the-stack.md](the-stack.md) names current
> vehicles, not permanent truths, and [benchmarks.md](benchmarks.md) quotes **no**
> specific scores on purpose — go to primary sources for live figures. Learn the
> primitives; they're what last.
